---
name: explicar
description: Explica código a un usuario que está aprendiendo Python. Usala cuando pida que le expliquen un archivo, una función o una decisión técnica.
---
Explicá $ARGUMENTS para alguien que está aprendiendo Python:

1. Resumen en dos oraciones: qué hace y para qué sirve en la app.
2. Recorrido por bloques, explicando cada parte en lenguaje simple.
3. Conceptos de Python que aparezcan y que quizás sean nuevos
   (decoradores, clases, comprensiones de listas, etc.), con un
   ejemplo mínimo de cada uno.
4. Por qué se resolvió así y qué alternativas había.
5. Terminá con una pregunta corta para que el usuario compruebe
   si entendió.
